# AQI-trend-Analysis-using-Predictive-Analytics
I completed a project on “AQI Trend Analysis Using Predictive Analytics,” where I analyzed and predicted AQI trends using ML techniques. Applied preprocessing, feature engineering, and models like Linear Regression, Decision Tree, KNN, SVM, and MLP. Achieved R² of 0.93 and ~85% accuracy, with insights using KMeans and PCA.
